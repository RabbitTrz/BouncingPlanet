跃动星球 · 关卡编辑器教程（策划版）
======================================================================
适用工程：C:\Users\28415\BouncingPlanet
Unity 版本：2022.3.62f3c1
最后更新：2026-11-03

一、打开编辑器
----------------------------------------------------------------------
1. 用 Unity 打开 BouncingPlanet 工程。
2. 顶部菜单选择：
   Tools > BouncingPlanet > Level Editor
3. 第一次使用，如果没有 LevelDatabase：
   - 在编辑器窗口点“创建默认关卡”，或
   - 菜单选择 Tools > BouncingPlanet > Create Default Levels
   会生成：
   Assets/Resources/Levels/LevelDatabase.asset
   Assets/Resources/Levels/Level_1.asset
   Assets/Resources/Levels/Level_2.asset
   Assets/Resources/Levels/Level_3.asset
   Assets/Resources/Levels/Endless.asset
4. 不要手动移动、重命名或删除这些资产；需要改路径/结构先找程序。

二、界面说明
----------------------------------------------------------------------
顶部：Level 1 / Level 2 / Level 3 / Endless 关卡标签。
左侧：星球类型调色板；固定星球列表。
中间：关卡预览区。
右侧：关卡属性、技能、生成参数、类型权重、无尽参数、选中星球、验证结果。
底部：生成基线 / 生成预览、验证、保存。

预览区：
- 默认圆形预览，可在上方切回“展开预览”。
- 星球按类型显示不同颜色：
  Rock 蓝灰 / Bomb 橙 / Cloud 浅白 / Ice 青蓝 / Shiny 金黄
- 蓝色圆环 = 起始高度，绿色圆环 = 目标高度。
- 鼠标滚轮缩放（1x~8x）。
- 缩放到 >1x 后，底部和右侧出现滚动条：
  纵向滚动条移动可视半径窗口，横向滚动条旋转视角。
- 缩放按钮显示当前倍率，点击复位到 1x。

三、固定关（Level 1 / 2 / 3）制作流程
----------------------------------------------------------------------
1. 选择对应关卡标签。
2. 在右侧设置：
   - 显示名称 / 顺序
   - 目标高度（当前统一 11）
   - 起始高度
   - 本关允许的技能：无双 / 炸弹技能 / 钩锁
3. 调整“生成参数”和“类型权重”。
4. 点“生成基线”。
   注意：会覆盖当前固定星球列表，手工修改会丢失，弹窗确认后才执行。
5. 在预览区手工调整：
   - 单击星球：单选
   - Shift/Ctrl + 单击：多选/取消
   - 空白处拖动：框选
   - 拖动已选星球：整组移动
   - Delete / Backspace：删除选中
   - 右侧“删除选中”“复制选中”：批量操作
6. 点“验证”，处理错误和警告。
7. 点“保存”。
8. 运行 Game 场景，开始界面选择关卡；到达目标高度即通关。

注意：Level 1/2/3 是“生成后烘焙”的固定关卡。
生成一次后，星球列表就是固定数据，运行时不会重新随机。

四、手动编辑与撤销
----------------------------------------------------------------------
- 单选后右侧显示该星球的完整属性：
  类型、半径、角度、尺寸倍率、摆动幅度、摆动速度、备注。
- 多选时右侧显示“已选 N 颗”，适合批量拖动、删除、复制。
- 预览区的拖拽、增删、复制、生成，以及右侧属性修改，都支持 Ctrl+Z 撤销。
- 选中状态、缩放、滚动条平移属于视图操作，不会进入撤销历史。

五、无尽关
----------------------------------------------------------------------
1. 选择 Endless 标签。
2. 点“生成预览”查看当前种子的一段布局（预览不会保存成固定列表）。
3. 编辑无尽规则：
   - 密度随高度曲线
   - 最大密度
   - 无双/炸弹/钩锁解锁高度
4. 编辑生成参数、类型权重、种子。
5. 点“验证”，再进入游戏开始界面选择“无尽”测试。
无尽关没有目标高度，运行时会持续生成。

六、常用字段说明
----------------------------------------------------------------------
目标高度 goalRadius：
  固定关的胜利高度，默认 11。Endless 忽略。
起始高度 startRadius：
  玩家出生半径，默认 1.5。
技能开关：
  allowMusou / allowBomb / allowHook。
  未勾选的技能不会响应输入，对应 HUD/钩锁提示也会隐藏。
种子 seed：
  生成基线或无尽预览的随机种子。
  同一个种子 + 同一套参数会得到同样的结果。
密度 densityMultiplier：
  生成密度倍率。
轨道间距 laneSpacing：
  星环之间的半径间隔。
每环数量：
  ringCountMultiplier / minPlanetsPerRing / maxPlanetsPerRing。
间隙星球：
  gapCountMultiplier / gapRadialOffset / gapRadiusJitter。
尺寸/摆动：
  sizeJitter / swayMax / swaySlotRatio / swaySpeedMin / swaySpeedMax。
生成窗口：
  initialBelow / initialAbove / spawnAhead / backfillBehind /
  minGenerationRadius / recycleAbove。
类型权重：
  每项是一个 PlanetTypeDef 和权重；权重越大越容易生成。
固定星球条目：
  类型、半径、角度（0~360）、尺寸倍率、摆动幅度/速度、备注。

七、验证规则
----------------------------------------------------------------------
点“验证”后会列出错误（红色）和警告（黄色）：
- 目标高度必须大于起始高度。
- Baked 关卡不能没有固定星球。
- 星球不能缺少类型。
- 半径不能低于最小生成半径。
- 星球严重重叠会报错，轻微重叠会警告。
- 出生点附近没有安全落点会警告。
- 目标线附近没有星球会警告。
- 类型权重为空/0 会警告。
先处理红色错误，再根据黄色警告检查布局。

八、保存与提交
----------------------------------------------------------------------
1. 编辑器顶部或底部点“保存”。
2. 提交到 Git 时，关卡数据在：
   Assets/Resources/Levels/
   包括 LevelDatabase 和 Level_1/2/3/Endless。
3. 关卡是数据资产，不需要改代码。
4. 不要重复创建 LevelDatabase；已有数据库时编辑器会直接加载。
5. 如果改了 Assets/Config 下的全局数值，先通知程序并做 Config 快照。

九、测试流程
----------------------------------------------------------------------
1. 保存关卡。
2. 打开 Assets/Scenes/Game.unity，点 Play。
3. 开始界面选择对应关卡。
4. 检查：
   - 技能是否正确显示/隐藏；
   - 出生点是否安全；
   - 能否到达目标高度；
   - Endless 是否持续生成；
   - 关卡难度和星球类型是否合理。
目前编辑器里还没有“一键试玩”按钮，统一从 Game 场景开始界面测试。

十、注意事项
----------------------------------------------------------------------
- 固定关“重新生成”会覆盖手工修改，重要版本先保存/提交。
- Baked 关卡会在进入时加载全部固定星球；如果数量太多导致卡顿，先降低密度或每环数量。
- 技能开关会同时影响玩家输入和 HUD。
- 不要手动改 LevelDatabase 的引用列表；通过编辑器创建/维护。
- 美术 Raw/Image 资源不通过这个编辑器修改。
- 结构、字段或运行时规则需要调整时，先和程序确认，避免旧关卡失效。
